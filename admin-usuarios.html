Administradores

Quem pode entrar no painel. Só administradores conseguem criar novos acessos.

Tela de demonstração: os acessos abaixo são de exemplo e virão do banco quando o back-end estiver conectado.

Cada pessoa com o próprio acesso

Senha compartilhada impede saber quem fez cada alteração. Se alguém sair da equipe, o acesso dessa pessoa deve ser desativado no mesmo dia.

Novo administrador

A pessoa recebe um e-mail para criar a própria senha. Você não define a senha dela.

É por aqui que o convite de acesso será enviado.
