# Fotos da ONG

Coloque aqui as imagens reais (Instagram @ongfrutosdoamanha / Facebook
"Projetos Sociais Ong Frutos do Amanhã"), com estes nomes exatos:

| Arquivo | Onde aparece | Proporção sugerida |
|---|---|---|
| `hero-criancas.jpg` | foto de destaque do hero | 4:3 (ex. 1600×1200) |
| `feirinha-da-crianca.jpg` | card do projeto Feirinha da Criança | 3:2 (ex. 1500×1000) |
| `estudando-para-o-amanha.jpg` | card da campanha Estudando para o Amanhã | 3:2 (ex. 1500×1000) |

Dicas: exporte em JPG/WebP com menos de ~400 KB cada e mantenha o rosto das
crianças na área central da imagem (o recorte é `object-fit: cover`).
Se trocar os nomes, atualize os `src` correspondentes em `index.html` —
e revise o texto `alt` para descrever a nova foto.
